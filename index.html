Built

How I work

Spec first, then agents, then testing against the real system.

Across JobHunt, Callsheet and PriMed I have built three MCP servers that give Claude 126 tools to work with. I write the spec, direct AI coding agents to build it, and review and test what they produce. The hard part is rarely the first demo. It is getting an agent to run reliably every time and recover from popups, timeouts, logouts and bad states without a person stepping in.
